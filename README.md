# AirGestureController 隔空手勢控制器 v0.2.3

Android 10+ 本機前鏡頭手勢控制器，Samsung S26 Ultra 實機測試 v0.2.2 的五種操作均正常。

## v0.2.3 更新：食指游標覆蓋完整螢幕
- 修正 v0.2.2 食指只能移動到螢幕中央附近的問題：將前鏡頭辨識位置映射放大，讓小幅手指移動覆蓋更多畫面。
- App 新增「**食指游標活動範圍**」：原始 1 倍、擴展 2 倍、**全螢幕 3 倍（預設）**、極大範圍 4 倍。
- 移除游標在畫面 X 軸 3.5% 和 Y 軸 5.5% 以內無法進入的原限制；現在可移動至四周極近邊緣的位置。
- 避免游標圓點在四周邊緣時與真正點擊位置錯開：動態對齊游標熱點。
- 手指停穩 3 秒單擊、維持不連點的規則不變，並保留 v0.2.2 所有既有手勢與三色指示燈。
- 只有食指游標座標被放大，張開手掌上下滑／右滑返回及握拳中央點擊都使用原演算法；**支架辨識優化仍暫停**。
- 如果覺得 3 倍太靈敏，可以在 App 選 2 倍；如果伸手幅度仍不足，可選 4 倍。倍率越高，游標也越可能放大手指抖動，需要實機調整。

## 既有功能
- ✋ 張掌往上／往下：模擬上下滑動。
- ✋ 張掌往右：模擬螢幕左緣向右滑返回。
- ✊ 張掌後握拳：點擊畫面中心。
- ☝️ 只伸食指：游標跟隨，停穩 3 秒點一下。停止指向會關閉游標；不連點。
- 省電、智慧平衡、高反應 AI 推論模式；鏡頭畫面僅在本機運算，不錄影、不保存、不使用網路權限。
