# AirGestureController 隔空手勢控制器 v0.2.2

Android 10+ 的離線前鏡頭隔空控制。v0.2.1 在 Samsung S26 Ultra 的三項原始手勢已實機正常。**本次新增滑回上一頁與食指游標；兩項功能尚需實機驗證。**

## 手勢
- ✋ 張掌往上：向上滑動；張掌往下：向下滑動（保留原有判定）。
- ✋ 張掌往右：模擬從螢幕**最左側往右拉**的系統返回手勢，與上下滑需要明顯方向區別；不支援往左返回。
- ✊ 張掌後握拳：點擊螢幕正中央（原有功能）。
- ☝️ **只伸一根食指**（MediaPipe `Pointing_Up` 類別）：食指位置控制跨 App 懸浮游標。保持在相近位置 **3 秒**，游標環形進度完成後點一下。持續停住不會連點；移到明顯的新位置或重新伸出食指後才可再次停留點擊。
- 手掌執行動作後停穩約 0.5 秒可重新待命；其他原有操作保持。
- 食指移動會參照前鏡頭影像做水平鏡像轉換；第一次請在 S26 Ultra 確認游標方向與位置。
- 指示燈灰／綠／藍狀態與非觸控式懸浮游標，不另索取「顯示在其他 App 上層」權限。

## 暫不更動
- **支架傾斜辨識優化暫停**：本版未引入斜角追蹤濾波或降低手掌辨識門檻，以保護目前正常的正面辨識。
- 保留 省電／智慧平衡／高反應三種 AI 推論頻率模式。
- 不加入廣告、網路權限或影像錄製；所有辨識在本機執行。

## APK 更新與測試
- `applicationId=tw.airgesture.controller`，版本 `0.2.2`，`versionCode=4`。
- 正式簽章 SHA-256 應與 0.2.0/0.2.1 相同；可直接覆蓋更新。
- CI 進行 JVM 測試與 Android 編譯，驗證無 `INTERNET` 權限以及簽章指紋。
- 建議依序測試：正面上／下滑、握拳點中央、右滑返回、食指游標方向、停留三秒單擊、移開再點、橫向回上一頁不誤觸上下滑。
- 部分 App 與系統頁面可能限制模擬手勢；返回動作也可能受 Android 導覽模式影響。

編譯與正式簽章設定參見 `.github/workflows/build-apk.yml` 及 `SIGNING.md`。正式簽章資料僅存在 GitHub Actions Secrets。
