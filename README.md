# AirGestureController 隔空手勢控制器 v0.2.3

Android 10+ 本機前鏡頭手勢控制器，Samsung S26 Ultra 實機測試 v0.2.2 的五種操作均正常。

## v0.2.3 更新：食指游標覆蓋完整螢幕
- 修正 v0.2.2 食指只能移動到螢幕中央附近的問題：將前鏡頭辨識位置映射放大，讓小幅手指移動覆蓋更多畫面。
- App 新增「**食指游標活動範圍**」：原始 1 倍、擴展 2 倍、**全螢幕 3 倍（預設）**、極大範圍 4 倍。
- 移除游標在畫面 X 軸 3.5% 和 Y 軸 5.5% 以內無法進入的原限制；現在可移動至四周極近邊緣的位置。
- 避免游標圓點在四周邊緣時與真正點擊位置錯開：動態對齊游標熱點。
- 手指停穩 3 秒單擊、維持不連點的規則不變，並保留 v0.2.2 所有既有手勢與三色指示燈。
- 只有食指游標座標被放大，張開手掌上下滑／右滑返回及握拳中央點擊都使用原演算法；**支架辨識優化仍暫停**。
- 如果覺得 3 倍太靈敏，可以在 App 選 2 倍；如果伸手幅度仍不足，可選 4 倍。倍率越高，游標也越可能放大手指抖動，需要實機調整。

## 既有功能
- ✋ 張掌往上／往下：模擬上下滑動。
- ✋ 張掌往右：模擬螢幕左緣向右滑返回。
- ✊ 張掌後握拳：點擊畫面中心。
- ☝️ 只伸食指：游標跟隨，停穩 3 秒點一下。停止指向會關閉游標；不連點。
- 省電、智慧平衡、高反應 AI 推論模式；鏡頭畫面僅在本機運算，不錄影、不保存、不使用網路權限。

## 編譯與更新
`applicationId=tw.airgesture.controller`，版本 `0.2.3`，`versionCode=5`。
使用 GitHub Actions 保管的原始固定簽章；APK 無 `INTERNET` 權限。正式簽章、版號和 Android 測試通過後，可直接安裝覆蓋 v0.2.2。
首次測試建議確認游標能到四角、游標位置與實際點擊位置一致，以及原本五個手勢正常。

## 待測試程式碼：斜角張掌輔助（尚未發布／未編譯）

針對實測發現的問題：**左右手只要傾斜到相同角度，都容易無法辨識張掌**。這是角度相關問題，不是只支援右手。

最新原始碼已加入實驗性「斜角手掌辨識輔助」開關，**預設關閉**。原 MediaPipe `Open_Palm` 辨識仍優先；只有原分類不確定時，才利用 21 個手部關節點判斷四根長手指有沒有伸展，並要求連續兩次幾何證據（或延續近期已確認的張掌）。採相對骨節距離與角度，不區分左右手，亦不要求手掌朝上。對握拳、單指等高信心分類設有保護。指示燈可以短暫防閃爍，但沒有足夠證據時仍不觸發滑動。

- 現有 v0.2.3 安裝版本**完全不變**；`versionCode`、簽章與 APK 尚未更新。
- **遵照需求：本次只更新 GitHub 原始碼及待執行的單元測試，沒有執行 Gradle／GitHub Actions 編譯，也沒有生成 APK。** 因此未確認 Android 編譯或真機辨識成果。
- 此方法主要改善相機畫面內手掌旋轉造成的分類不穩。若手機支架造成嚴重透視變形、手指互相遮擋或關節點辨識失敗，純 2D 幾何未必有效。
- 正式編譯並實測時，建議先在未開啟輔助的狀態複測正面辨識，再開啟輔助比較左右手各種傾斜角度，以及握拳點擊、右滑返回、食指游標與耗電量。
