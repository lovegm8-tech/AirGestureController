# 張掌喚醒實驗版（WakeProbe v0.1.1）

**目的**：在 Samsung S26 Ultra 上實測「手機熄屏 → 張掌 → 亮屏 → 三星臉部解鎖 → 保留原影片畫面 → 張掌握拳模擬點擊影片中央」能否實現。特別要釐清熄屏後 CameraX 能否持續收到畫面、Android 是否允許喚醒，以及解鎖後能否重新取得前鏡頭。

## 與正式 App 隔離

- 獨立 Gradle 專案 `wakeprobe/`，APK 套件名 `tw.airgesture.wakeprobe`，**不取代** `tw.airgesture.controller`（正式 v0.2.4）。
- **不要同時運作**正式 App 與 WakeProbe，避免兩個程式同時爭用前鏡頭。
- 使用者自行從畫面明確啟動，最多運作 8 分鐘；通知可以立即停止。
- 無錄影、無相片儲存、無網路權限、無暗中喚醒。Log 僅在本機 SharedPreferences 記錄時間、畫面處理張數、手勢是否辨識、喚醒請求、是否收到系統已解鎖事件、模擬點擊是否被允許；不保存影像或臉部特徵。
- 不會嘗試繞過手機鎖定：觸控僅在 `isInteractive && !isKeyguardLocked` 時才會進行。
- 先讓影片停留在原先正在看的頁面，將 WakeProbe 最小化，再關螢幕。若系統的臉部辨識設定需要解鎖後另外向上滑，必須在三星設定將「留在鎖定畫面直到滑動」關閉。

## 實機操作

1. 停止正式 AirGestureController 前鏡頭服務（避免攝影機衝突）。
2. 啟動 WakeProbe，按「設定實驗用無障礙服務」開啟該實驗 App 的服務。允許相機及必要的通知權限。
3. 在 Samsung 設定中確認臉部辨識正常，並視需要關閉「留在鎖定畫面直到滑動」。
4. 開啟要測試的影片並暫停、保持該 App 在前景；啟動 WakeProbe 測試後，切回影片，按手機電源鍵熄屏。
5. 對前鏡頭**連續張掌約 1 秒**。如果系統繼續送相機影格且亮屏權限許可，程式會先釋放攝影機，嘗試喚醒螢幕。**系統可能拒絕喚醒**。
6. 交由三星原本的臉部解鎖機制（**不代替指紋／密碼**）；解鎖後回到原影片，對鏡頭張掌再握拳，送出一次螢幕中央點擊。
7. 回實驗 App 查看時間軸，分別確認「熄屏期間實際收到相機畫面」、「已要求亮屏」、「螢幕已亮」、「Android 回報已解鎖」及「中央點擊」等事件。如未能亮屏，可手動解鎖回實驗頁查看記錄。

## Android 系統限制

- Android 14+ `PowerManager.ACQUIRE_CAUSES_WAKEUP` 可能要求 `android.permission.TURN_SCREEN_ON` 特殊權限，且這兩個接口已有棄用／限制，實測不能視為保證。
- 系統也可能在螢幕關閉時暫停攝影機；若沒有畫面，程式無法偵測張掌。
- 系統臉部辨識使用同一個前鏡頭，因此程式會在喚醒前**先釋放鏡頭**，等 Android 回報完成解鎖後再重新啟動監測。若醒來後攝影機權限受背景啟動限制，第二次相機綁定也可能失敗。
- 中央點擊只是模擬觸控：不同影片播放器可能採取不同的暫停／播放互動，不能保證每個播放器都會回復播放。
- 手機置放、熄屏頻繁監控可能增加耗電與發熱。本專案限定短期實驗並設定自動停止，**不適合直接當成長時間待機功能**。

## 編譯

在 `wakeprobe/` 跑 `gradle :app:testDebugUnitTest :app:assembleRelease`；固定簽章在儲存在受信任 GitHub Actions Secret 的工作流程中產出，不寫入原始碼。只需要實驗 APK 時使用一次性 `.github/workflows/build-wakeprobe-once.yml`，完成後刪除自動觸發器。

## v0.1.1 相機交接改善

- 張掌成立後不再固定等待 250ms 即亮屏，而是先 `unbindAll`、監聽 CameraX 的 `cameraInfo.cameraState`，確認 `CLOSED` 後再等 400ms 才嘗試喚醒；最多等 3 秒，如果仍未確認完全關閉，當次不主動亮屏，避免干擾三星臉部辨識。
- 即使使用電源鍵而不是張掌亮屏，收到 `ACTION_SCREEN_ON` 也會立即停止相機分析並釋放 CameraX，避免繼續占用相機。
- 解鎖後延長至約 2 秒再重新啟動前鏡頭，讓三星先完成臉部辨識；仍遵守 Android 14+ 背景相機啟動限制。
- 紀錄相機從 OPEN/CLOSING/CLOSED 的狀態轉換，有利於區分「釋放太慢」與「系統不主動觸發人臉辨識」。
- 仍需 S26 Ultra 實機驗證；即使釋放成功，三星系統未必會重試因相機被占用而錯過的臉部辨識。
