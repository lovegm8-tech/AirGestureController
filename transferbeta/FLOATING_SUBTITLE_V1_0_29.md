# 懸浮操作 v1.0.29 — 直接在影片上手動框選字幕

## 為何改用框選
前面 v1.0.23–v1.0.28 的全螢幕 OCR，在 YouTube 直向一般影片多次把搜尋結果／推薦標題誤判成字幕，使用者提供 5887.mp4 影片回報。無論對所有文字評分或調高播放器上半部優先權，若 OCR 沒辨識到目標文字，依然可能選錯。

v1.0.29 的預設流程 **不讓程式猜字幕在哪裡**。使用者在播放的影片上，決定字幕辨識區域。

## 操作
1. 開啟「懸浮翻譯」→ Android 畫面擷取授權請選「**分享整個螢幕**」。
2. App 會退到背景，綠色框選介面會蓋在原來影片上；如果此時不是影片，按「切換影片」暫時隱藏整面編輯介面，前往 YouTube/TikTok/瀏覽器；再點畫面旁的「框選字幕」浮鈕。
3. 按住**框內拖曳**來移動；**拉四角圓點**改變寬度和高度，恰好覆蓋英文字幕（建議略多留上下邊界以支援換行）。
4. 按「完成框選」後，完整編輯框消失，只 OCR 綠框中的原文。中文仍盡量顯示在原文字框上方，原字幕和中文不重疊。
5. 此位置會依**直向 / 橫向**分開存在本機 SharedPreferences；下次翻譯啟動會顯示儲存的框，能直接按「完成框選」。
6. 想調整框：通知欄「框選字幕」或 App 首頁「重新框選字幕範圍」。如影片旋轉，會讓使用者確認對應方向的框，避免錯誤掃描。
7. 按「停止翻譯」結束 MediaProjection 和所有編輯浮窗。

## 實作與安全
- 新增 `SubtitleRoiEditor` 透明覆蓋 View，支援拖動、四角大小調整、邊界限制。
- 框選期間**暫停 OCR**；控制編輯浮窗設定 FLAG_SECURE，避免重新拍到自己畫出的綠框。
- 確認框選後只擷取選定的實際像素矩形，必要時先放大以改善小字 OCR；OCR 文字框轉換回螢幕座標，保留原翻譯跟隨位置的功能。
- 視窗方向分別儲存框選比例，無伺服器、無畫面儲存或上傳。
- 保留舊版翻譯模型、來源語言（英文／日文／韓文）、原有診斷資訊。
- 核心 NFC、Nearby、前鏡頭手勢程式沒有更動。
- 套件 ID `tw.airgesture.transferbeta` 不變，versionName 1.0.29，versionCode 42；CI 用原 Secrets 正式簽章驗證。

## 回歸測試
- 用前次 5887 哈利波特直向一般影片，將框移到播放器上方的英文台詞，不把搜尋結果包含進框。驗證字幕是否正常更新，且不再出現 `Tharry Potter Efseskh`。
- 橫向全螢幕字幕測試；切直向後確認不同位置的框。
- 在 YouTube Shorts 直向、TikTok／瀏覽器中改框測試。
- 另外測手勢、NFC 碰一碰與 Nearby 檔案傳送。
- 測試畫面擷取中斷、按停止翻譯後綠框清除，避免殘留觸控阻擋。

## 已知限制
Android 畫面擷取權限每次新工作階段須授權；受 DRM 保護的影片仍可能不能擷取。手動選框可以解決**抓錯畫面文字**，但若影片字幕字型太小／背景模糊、OCR 文字辨識錯誤，或 ML Kit 離線翻譯模型品質不足，翻譯仍可能錯字或殘留英文。這些問題仍需實機確認。
