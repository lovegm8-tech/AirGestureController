# 懸浮操作 v1.0.31 — 英文／日文離線語音補位（實驗版）

以 v1.0.30 現有的 NFC、Nearby、手勢、手動 OCR 框與常駐懸浮小球為基礎。
原 Android applicationId `tw.airgesture.transferbeta` 不變，versionName `1.0.31`，
versionCode **44**，使用原 GitHub 正式簽章驗證。

## 使用者需求
- 使用者在真實 YouTube 影片上手動框選字幕後，字幕位置較準確，但字幕變化太快時仍可能漏譯。
- 同時想看動漫，日語對白即使沒有字幕或 OCR 來不及，也需要語音辨識補位。

## 本版實作
1. 首頁獨立可關閉的「**英文／日文語音補位（實驗版）**」開關，預設關閉。
2. 若來源語言是「英文字幕」，語音引擎用 Vosk `vosk-model-small-en-us-0.15`（約 40 MB，Apache-2.0）。
3. 若來源語言是「日文字幕」，語音引擎用 Vosk `vosk-model-small-ja-0.22`（約 48 MB，Apache-2.0）。
4. 韓文目前仍只有 OCR，不啟用語音引擎；切換韓文時語音補位自動關閉。
5. 啟用需授予 Android `RECORD_AUDIO` 權限及畫面擷取授權，使用 `AudioPlaybackCaptureConfiguration` 僅擷取允許的其他 App 的 MEDIA/GAME 播放音訊，**程式不會從手機麥克風收音**。
6. Android 14+ 啟動 MediaProjection 與 microphone FGS type（音訊讀取 Android 權限要求），保持使用者可見持續通知。
7. 語音轉文字由手機端 Vosk 離線進行；將選定語言原文交給原 ML Kit 翻譯器（英翻中、日翻中），再使用既有繁體轉換及中文字幕。
8. **OCR 字幕優先**：最近 2.3 秒 OCR 有成功字幕輸出，語音結果不覆蓋；部分口述去重、相隔約 1.9 秒才允許補位，並在 OCR 翻譯與語音翻譯使用分開的忙碌旗標，避免語音阻塞 OCR。
9. 只有語音翻譯確實輸出中文字時才顯示，不把未翻的英文／日文原文偽裝成中文字幕。
10. 語音結果顯示在畫面約 68% 高度；OCR 翻譯仍按照手動框內英文或日文字幕位置顯示在原文上方。
11. 原有字幕框選、小球的重框選、暫停／恢復、停止等操作全部保留。暫停時兩引擎皆不更新翻譯。
12. 診斷畫面增加「語音補位狀態／語音原文」，與 OCR 原文、候選排名並列。

## 模型下載及裝置資源
- 英、日模型按使用語言各自下載一次，資料存放在 App 私有檔案夾；再次啟用不需重下載。
- 模型下載來源為官方 `https://alphacephei.com/vosk/models/`，不經自己的伺服器。
- 模型 zip 安裝有容量、展開檔案數與 Zip Slip 路徑防護、完成標記，避免不完整模型被誤用。
- Vosk 小模型運作時每套可能使用約 300 MB 記憶體，**只載入選中語言的模型**。可能增加 RAM、電池與發熱。
- 受音訊政策限制的 YouTube／串流平台可能仍無法擷取內部聲音；畫面有 DRM 不支援繞過，並保留純 OCR 模式。
- 官方文件：[Vosk Models](https://alphacephei.com/vosk/models)、[Vosk Android 安裝](https://alphacephei.com/vosk/install)。

## S26 Ultra 實機測試
1. 安裝版號 v1.0.31/code44 的同簽章 APK，確認 NFC/Nearby/手勢原設定仍在。
2. 開啟「英文字幕」＋「英文／日文語音補位」，同意音訊權限；打開英文影片，系統畫面擷取授權請選整個螢幕。
3. 在影片字幕上完成綠框，語音引擎首次使用會下載英文約 40 MB 模型；觀察 OCR 會優先顯示，停掉 CC 字幕時是否改由語音補位。
4. 切成「日文字幕」，重新啟動懸浮翻譯並下載日文約 48 MB 模型；播放動漫或日語影片；必要時讓字幕框選到現有日文字幕，或不框到任何字幕以觀察語音補位。
5. 變更播放器位置可點常駐「譯」小球重新框選，不用關閉語音補位。
6. 看診斷「語音補位狀態」是否顯示已啟動、未取得可讀播放音訊、下載失敗，區分平台限制與辨識錯誤。
7. 暫停、恢復及停止時，驗證 OCR/語音都受控且音訊資源在停止後釋放；測遊戲三開時耗電與溫度。

## 已知限制
- 語音不像既有原字幕一樣提供即時時間軸，會有延遲，短句與背景音樂可能仍翻得不準。
- 只錄允許的內部播放聲音，不會使用外部麥克風替代，也不保證所有第三方 App 都可擷取。
- CI 編譯、單元測試與簽章驗證並不代表 S26 Ultra 真實錄音成功；此 PR 仍應維持 Draft 等實測。
