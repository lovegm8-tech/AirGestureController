# 懸浮操作 v1.0.42｜字幕逐階段診斷與有條件 OCR 優先

**基線：v1.0.41。** 修改範圍僅 transferbeta 懸浮翻譯模組，手勢、NFC、Nearby、檔案傳輸與主畫面縮小邏輯維持不變。

- **診斷：** 原有現場診斷面板新增最近 60 筆語音 Vosk 原始 partial/final、ASR 已切分片語、OCR 候選文字、ML Kit 快譯、Qwen 修正以及畫面顯示內容。資料只保留在記憶體，不會自動上傳或存成檔案；停止翻譯後清除。
- **防止舊結果覆蓋：** Qwen 異步回覆必須確認原本那版 ML Kit 譯文仍在畫面上；已由新語音或 OCR 更新則忽略遲到 AI 譯文。
- **OCR 保守優先：** 語音辨識正常時，每約 1.2 秒試探一次有無原文字幕；原文需跨至少兩張 OCR 影格相同，且在可信影片範圍內，才優先顯示 OCR 翻譯；若畫面沒字幕超過 2.1 秒則交還語音路徑。手動框選也必須兩影格穩定。
- **保留即時性：** Vosk 繼續聽播放音訊，ML Kit 快譯先顯示，Qwen 沿用至少 7 秒一次的節流。
- **版本/簽章：** 1.0.42 / versionCode 55；套件名稱 tw.airgesture.transferbeta、ARM64、原正式簽章金鑰，透過專屬 GitHub Actions 測試建置。
