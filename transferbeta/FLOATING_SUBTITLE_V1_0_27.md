# 懸浮操作 v1.0.27 — S26 Ultra 實機字幕回歸（5882 / 5883）

基底 `feature/floating-subtitle-ocr-v1-0-26`，套件 `tw.airgesture.transferbeta`，
版本 `1.0.27`、versionCode 40，沿用既有發行簽章。

## 實測現象

- 5882.mp4（手機直向、YouTube 一般觀看）：英文字幕在上方播放器底部，但是翻譯框反覆出現下方中文推薦標題，例如 Lofi Chill 一類影片文字。
- 5883.mp4（橫向全螢幕）：已有中文字幕跟隨影片更新，但片段、括號說明以及專有名詞仍可能翻譯不完整或有英文殘留。

## 修正

- 全螢幕 OCR 仍然存在；直向影片每隔一次 OCR 額外掃描上方 **37.5%** 畫面，放大為 **1.8 倍**。舊版上方 47% 的掃描區含下方推薦清單標題，這次排除。
- 字幕候選排序：直向字幕多位於約畫面 12–36.5%（播放器內），大幅降低約 37–63% 下方網頁 UI 的選取優先序；短影音下方字幕仍保留辨識可能。
- 英文 OCR 新增中英文佔比過濾。以中文字為主、僅夾少數英文字的影片標題或舊翻譯不會再當作英文台詞。
- 「查看字幕辨識診斷」擴充 **OCR 候選文字排名與縱向位置百分比**，並顯示翻譯是否含大量英文，以便確認是文字選錯、漏字或離線翻譯模型的品質問題。
- 不自動刪除翻譯中的所有英文字母：英文專有名詞也可能是正確結果，不能冒險破壞翻譯。先以診斷確定原因。
- 添加真實影片情境的純邏輯測試：直向英文字幕應勝過標題／推薦清單、英中混合標題不應被當成英語字幕、Shorts 仍可於下方辨識。

## 測試步驟

1. 用同簽章的 `1.0.27` APK 直接覆蓋安裝；查看版號與版本代碼是否為 **40**。
2. 繼續使用「字幕辨識位置：整個螢幕」，來源「英文字幕」，並選 Android「分享整個螢幕」。
3. 重播錄影 5882 的 YouTube 一般直向影片，確認字幕上方的英文台詞被中文翻譯，而不是下方 Lofi Chill 推薦標題。
4. 再測錄影 5883 的橫向影片：查看中英文同步、字幕框相對位置及翻譯有無英文殘留。
5. 如遇錯誤：在「查看字幕辨識診斷」記下 **掃描模式／OCR 原文／翻譯結果／候選排名／翻譯品質**。
6. 檢查手勢、NFC 碰一碰和 Nearby 檔案傳送；核心程式完全未更動。

## 已知限制

這仍使用本機 ML Kit OCR 與離線翻譯。改善正確原文的選擇、合併片段可減少錯譯，但不保證離線翻譯具備大模型同等能力，或完全消除英文專有名詞。影片畫面受到 DRM 保護時，無法繞過系統擷取限制；沒有外語字幕的純語音影片尚未支援語音翻譯。
