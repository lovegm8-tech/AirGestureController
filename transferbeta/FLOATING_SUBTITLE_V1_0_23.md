# 懸浮操作 v1.0.23 — 第一版 OCR 懸浮字幕（實機測試版）

基底：`experiment/floating-control-integration`（v1.0.22、versionCode 35）。
測試分支：`feature/floating-subtitle-ocr-v1-0-23`。
目前版號：v1.0.23、versionCode 36、applicationId 維持 `tw.airgesture.transferbeta`，原 NFC/Nearby/手勢程式碼未調整。

## 功能
- 首頁「功能獨立開關」新增「懸浮翻譯」；與前鏡頭手勢、附近傳檔完全獨立。
- OCR 檢查影片畫面下方約 40%，並將文字轉成中文（再進行簡繁轉換），使用可拖曳懸浮框顯示。
- 英文、日文、韓文 OCR 三擇一，翻譯進行中不可切換來源語言；預設英文。
- 每約 1 秒掃描一次，遇到重複的原字幕不重送翻譯；Android 14+ 每次開啟新擷取工作階段都必須由使用者授權。
- 第一版不擷取麥克風／播放音訊，不自動辨識語音、不上傳影像，也沒有付費雲端 API。ML Kit 翻譯模型首次可能需要在 Wi-Fi 環境下載，之後可離線使用。
- 停止開關或從通知欄停止後釋放 MediaProjection、ImageReader、字幕 Overlay、OCR 與翻譯資源。

## S26 Ultra 測試順序
1. 用同一正式憑證簽章且較高 versionCode 的 v1.0.23 APK 覆蓋安裝。
2. 開啟主頁，先驗證「前鏡頭手勢」與「附近裝置傳檔」原有狀態正常。
3. 選「英文字幕」→ 打開「懸浮翻譯」→ 允許懸浮顯示及系統「開始錄製或投放」畫面授權。
4. 播放 YouTube 有英文字幕的影片（盡量使用未受保護的內容），觀察字幕準確率與更新間隔。
5. 手指拖曳中文字幕，橫屏與直屏播放；返回 App 用開關關閉，再從通知欄啟動並停止。
6. 分別選日文、韓文，重啟翻譯進行測試；首次翻譯模型下載應接上 Wi-Fi。
7. 切換 NFC 碰一碰、Nearby 分享和遊戲前景手勢暫停情境，確認原服務沒有因 OCR 停止或重啟。
8. 比較同一影片在「翻譯關閉」與「翻譯開啟」15 分鐘的溫度及系統電池統計。

## 已知限制與待測
- 識別字幕需來源影片已有可見文字；只剩語音、沒有字幕的影片要等語音翻譯模組。
- 來源語言未自動偵測，須手動選英／日／韓。
- 不能繞過其他影音 App 的 DRM 或禁止螢幕擷取限制。
- 簡繁轉換不是完整的臺灣詞彙校正；部分翻譯可能不自然。
- 螢幕擷取仍需 Android 系統即時授權，無法做成無提示的永久擷取。
- 尚未做 S26 Ultra 實機測試；CI 只負責 JVM 單元測試、編譯、簽章與套件資訊驗證。

## 架構隔離
手勢／傳檔服務 `GlobalGestureService`、`MultiPeerTransferManager`、NFC 卡片模擬、信任裝置資料、簽章 Secret 均不變。OCR 的獨立 `SubtitleCaptureService` 使用 `mediaProjection` 前景服務類型，其關閉不會停止 NFC 或 Nearby。切換 OCR 不改動原本相機權限或手勢辨識。
