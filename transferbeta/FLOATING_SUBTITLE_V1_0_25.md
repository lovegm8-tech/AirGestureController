# 懸浮操作 v1.0.25 — 全螢幕 OCR / 原字幕上方顯示

**基底：** v1.0.24，版本代碼 38，套件 ID `tw.airgesture.transferbeta`。
只改動 OCR 字幕功能及首頁字幕預設值，不修改手勢、NFC 或 Nearby 程式邏輯。

## 使用者要求
- 不再依網站或直／橫螢幕限制 OCR 掃描區域；預設擷取整個畫面並判斷哪些文字最像字幕。
- 中文翻譯盡可能直接顯示在辨識到的外語字幕**正上方**，不能把原字幕遮住。
- 翻譯框可手動拖曳，拖曳後固定該位置、不自動跳回。
- 保留原有來源語言設定、舊掃描區域作為備援。

## 實作
- `SubtitleRegionPolicy.FULL_SCREEN` 完整擷取 Y=0–100%；從 v1.0.24「智慧區域」0 預設設定一次性遷移到全螢幕設定4。已手動選過其他區域者仍維持選擇。
- 根據 Text Recognition 文字方框，每段字幕連同座標經 `SubtitleCandidatePolicy` 篩選（中央對齊、文字長度、橫向字幕常見垂直位置、時間上是否在同一個位置變動、排除狀態列文字等）。
- 候選內容連續多影格完全不變（容易是影片標題或導覽文字）則降低優先度，避免只翻譯固定標題。
- 辨識到字幕後使用來源方框螢幕座標，於翻譯文字更新時自動定位至來源字幕上方（有空間才放上方，不足時放下方），並以實際量測的中文框高度預留間距。
- 使用者手動移動超過 8dp 後停止自動跟隨，翻譯重新開啟會恢復自動定位。
- OCR 篩選純邏輯附 JVM 單元測試；正式簽章、安裝套件／版本代碼驗證使用既有 Actions Secret。

## 手機測試
1. 安裝 v1.0.25 並確認版本代碼 38。開啟 App 的「字幕辨識位置」，選「整個螢幕（自動尋找字幕，預設）」。
2. Android 畫面分享請選「分享整個螢幕」，而不是只分享懸浮操作 App 的畫面。
3. 播放同一段橫向 YouTube 英文字幕：觀察中文是否跟著字幕改變、是否出現在英文字幕上方。
4. 返回一般直向觀看與短影音檢查，注意中文字幕有無蓋住原文；試著手動拖動再播新字幕，檢查是否保持手動位置。
5. 畫面頂端字幕若上方空間不足，中文會改放下方以避免遮住來源。
6. 若誤判標題或固定按鈕，關閉翻譯 → 使用「自訂位置」縮小 OCR 範圍 → 再啟用；拍攝完整 10 秒影片回報。
7. 再測原本 NFC 碰一碰、Nearby 連線與手勢模式是否正常。

## 限制
- 全螢幕 OCR 可讀取其他 UI 文字，候選排序可降低誤判但不能保證 100%。
- YouTube 若關閉 CC 或影片沒有顯示可辨識原文文字，本版無法翻譯純語音。
- 字幕框顯示上方須有足夠空間；沒有空間時改在下方，仍不遮蔽原文。
- 全螢幕 OCR 比固定裁切成本高，S26 Ultra 的發熱和耗電需要實機驗證。
- DRM 或 App 禁止 MediaProjection 擷取時，無法繞過限制。
